\# 心形流水灯逻辑模拟 (Heart-LED-Simulation)

\## 📌 项目简介

由于目前硬件开发板尚未到货，本项目使用纯 C 语言在终端（Console）模拟单片机控制 LED 流水灯的底层逻辑。



\## 🧠 核心知识点

\- \*\*位运算\*\*：使用 `>>`（右移）和 `\&`（按位与）提取二进制位，精准模拟单片机寄存器的高低电平操作。

\- \*\*状态数组映射\*\*：使用十六进制数组（如 `0x18`, `0x24`）定义心形图案，通过遍历数组实现流动效果。

\- \*\*底层控制思维\*\*：不直接对整体端口赋值，确保在真实硬件上不会影响其他引脚状态。

\- \*\*软件延时\*\*：实现了基础的 `delay` 函数以控制流水灯节奏。



\## 🚀 后续计划

硬件板卡（STM32等）到位后，将直接把这套逻辑移植到单片机的 GPIO 寄存器控制中，结合真实的 LED 电路实现硬件演示，并在此基础上扩展按键中断控制等功能。
